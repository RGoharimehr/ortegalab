HFO-1234yf Two-Phase Pressure Drop Estimator

Version 1 — standalone browser app using a simple homogeneous two-phase friction model.

Disclaimer — estimation tool only. This file estimates frictional two-phase pressure drop for HFO-1234yf. Version 1 omits acceleration pressure drop, static head, fittings, roughness effects, and slip-ratio correlations. The built-in saturation table is seeded from the Opteon YF / HFO-1234yf SI datasheet, while the viscosity columns are editable estimates included only so Reynolds number and friction factor can be estimated. Verify final refrigerant properties, dimensions, and design margins independently before use.

Model notes

  • Model basis: homogeneous two-phase Darcy-Weisbach friction estimate.
  • Average quality: uses xavg = (xin + xout) / 2.
  • Mixture density: 1 / ρmix = x / ρv + (1 - x) / ρl.
  • Mixture viscosity: simple harmonic-in-quality estimate built from the editable liquid and vapor viscosity estimates. This is a version-1 simplification, not a rigorous correlation.
  • Friction factor: laminar 64/Re; otherwise turbulent Blasius 0.3164 / Re0.25. Transitional flow is not treated specially in v1.
  • Pressure drop: friction only. Acceleration, static head, fittings, roughness, and slip effects are omitted.
  • Load basis: when load is selected, the tool uses the latent-only relation |Q| = ṁ · hfg · |xout - xin|.
  • Pressure display: saturation pressure is a state property and may be shown as absolute or gauge pressure. Pressure drop is always a differential loss, so psi-based drop results are displayed as psi or psid, never as psig.
