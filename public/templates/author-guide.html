Write once in LaTeX

Download the LaTeX template, then open it in Web Admin → White Papers. Paste or edit source directly, compile a preview, and save. Check Published when the paper is ready. Every published paper gets its own page.

One shared format

Enter title, authors, abstract, year and tags in the metadata fields. Put the body between \begin{document} and \end{document}. Use sections for Introduction, Methods, Results, Discussion, Limitations, Conclusions and References. The website controls fonts, spacing, colors and responsive layout.

Supported content

Use \section, \subsection, paragraphs, emphasis, lists, standard math, figure with \includegraphics and \caption, and table with tabular. Equations are rendered as MathML. Tables scroll on small screens.

Use Upload a figure in the editor. Insert the returned /uploads/... path into \includegraphics{...}. Only uploaded or site asset PNG, JPEG, WebP and GIF images are supported. Caption figures descriptively. Keep references inside the document; external bibliography files are not loaded.

Compile and review

Compile preview does not publish or save. Changing the source makes the preview stale. Save compiles the source again, and a compilation error leaves the saved paper unchanged. Existing block content is converted to editable LaTeX when opened; the current published page remains unchanged until a successful save.

This is LaTeX-to-web compilation using Pandoc, not a full TeX engine or a PDF generator. Custom document classes, layout packages, TikZ, shell commands, external file inclusion and external bibliography processing are not supported. Unsupported commands may cause a compiler error; use the provided template and review the output. A separately prepared PDF can still be attached as an optional download.

Source files are limited to 100 KB; compilation is limited to 15 seconds. Use Download source to keep an editable copy. For a large report, remove unused macros and package-specific layout instructions.
