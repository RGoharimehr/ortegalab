White paper author guide

Start every report from the shared Word template. Save a copy for your report. The template is a starting document; its example page breaks can be removed as your content grows.

Use the shared structure

Fill in the title, authors, affiliations, report identifier, version, date and tags. Follow the section order: Abstract, Introduction, Methods, Results, Discussion, Limitations, Conclusions and References. Acknowledgments and Appendix are optional.

Use Word’s Title, Heading 1, Heading 2, Normal and Caption styles. Paste text without source formatting. Keep the supplied fonts, margins and spacing so papers remain consistent.

Figures and tables

  • Replace the placeholder using Change Picture, or insert an image in line with text. Keep it within the text width and preserve its proportions. Add descriptive alternative text.
  • Place figure captions below images and table captions above tables. Copy the example caption, including its number field, or use Word’s Insert Caption with the Figure or Table label.
  • Update all fields before export so figure and table numbers are sequential. Refer to each figure and table in the text.
  • Use editable tables with a header row, units and consistent precision. Repeat the header on subsequent pages. Avoid screenshots of spreadsheets.
  • Keep plot labels legible at final size; state units, operating conditions and uncertainty. Include source credits where applicable.

Review and publish

  1. Replace every instructional placeholder. Check citations, numbering, spelling, authors and permissions.
  2. Export to PDF and inspect every page for clipped tables, small figures, detached captions and awkward breaks.
  3. In Web Admin → White Papers, create a draft and enter matching metadata and tags, then upload the PDF.
  4. Add the webpage’s sections, text, figures and tables with the shared content blocks. The website controls their formatting. The Word document, PDF and webpage content are maintained separately; uploading a PDF does not automatically import its contents.
  5. Review the PDF and page content before publishing. Publishing creates the public paper entry and its individual page.
