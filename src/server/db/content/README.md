# Curated lab publications

`publications-july-2026.json` contains the 33 citations in the user-supplied
“Ortega Group Recent Publications as of July 2026.docx”, received September 30, 2026.
Each source citation is preserved verbatim alongside its extracted display fields.
DOIs come only from the supplied document. Presentation-only entries retain that label;
October 2026 entries are labelled forthcoming at the time of import.

The one-time database migration inserts missing entries, comparing normalized titles
and DOI URLs. It does not overwrite existing editorial changes or restore entries
that an editor deletes after the migration has run.
